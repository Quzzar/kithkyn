# KithKyn: Hearth and horizon

Every village, a story.

The hearth emblem gathers three homes around one flame. The name is KithKyn: both Ks are
capitalized. The repository and Minecraft mod ID remain kithkyn.

## Files

- kithkyn-primary.png: full-color horizontal lockup for light backgrounds.
- kithkyn-reversed.png: pale horizontal lockup for dark backgrounds.
- kithkyn-monochrome.png: one-color lockup with negative-space details.
- kithkyn-wordmark.png: standalone lettering for compact layouts.
- kithkyn-emblem.png: standalone village/hearth symbol.
- kithkyn-icon-32/64/180/512.png: browser, touch and app/launcher icon exports.
- kithkyn-social.png: 1200 by 630 social-sharing artwork.
- Matching WebP files: trimmed, lossless web versions.
- village-diorama.webp: original illustrated village key art.
- Font files and OFL licenses: Bricolage Grotesque and Outfit.
- generation-prompts.md: the final built-in image-generation prompts and provenance.

These are raster assets with true transparency, not vector originals. Keep the aspect ratio.
Leave clear space of at least one hearth-flame width on every side of a logo. Use the emblem
when the full lockup would become unreadable, preferably at 48 pixels or larger. Use the
32-pixel export only for favicons. Keep its three-house silhouette intact.

## Palette

Pine #23483f; Mist #eef3ed; Meadow #9cba9e; Honey #f5c45b; Sky #cddfe7.
Pine on mist is the default text combination. Honey is an action accent with pine text.
Meadow and sky are supporting fields, not small text colors.

## Type and voice

Bricolage Grotesque is the display face; Outfit carries body copy and controls. Keep headlines
short, bold and warm. Talk about neighbors and village life. Avoid claims that planned features
or public download destinations have shipped.

## Imagery

The village diorama and social banner are generated promotional illustrations. Label that
distinction when they could be mistaken for screenshots. Building previews on the website
are actual catalog-review captures, not natural-terrain or autonomous-growth evidence.
No borrowed Valecraft imagery is used in this identity.
