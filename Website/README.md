# Kithkyn website

The public website for [kithkyn.com](https://kithkyn.com). It introduces Kithkyn through the
autonomous life of one village, then grows into installation, development, and village-region
pages as those needs are defined.

## Development

```sh
bun install
bun run dev
```

Quality checks:

```sh
bun run build
bun run lint
bun run format:check
bun run test:e2e
```
